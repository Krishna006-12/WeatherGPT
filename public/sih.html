Use cases covered

  • Farmers — Farm mode irrigation / spray / soil
  • Travel / urban — Travel risk, visibility, AQI
  • Schools — heat / outdoor PE advisories
  • Flood / disaster — GDACS + flood discharge + push
  • Aviation (lite) — educational snapshot, not METAR release
  • Researchers — climate monthly series + model spread

Evaluation parameters

  • Accuracy — answers cite live packs; no invented sources
  • Latency — edge/serverless JSON; client cache with short TTL
  • Multilingual — HI/EN UI + voice
  • UI / a11y — mobile PWA, focus rings, TTS listen
  • Scalability — stateless APIs, CDN static, no DB required for demo
  • Innovation — explainable decisions, multi-model NWP, multi-city alert watch, agent-open API
