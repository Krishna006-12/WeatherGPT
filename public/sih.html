🏆 Core Innovation Summary

  • Real-Time Live Met Pipeline: Open-Meteo live API integration for 40+ Indian cities with automatic Geocoding search across India.
  • Grounded AI Copilot with Voice: Retrieve-then-phrase RAG engine + Web Speech Recognition (STT) + Speech Synthesis (TTS) in Indian English and Hindi.
  • Multi-Model NWP Ensemble: NOAA GFS vs ECMWF IFS vs DWD ICON spread comparison and ensemble confidence calculation.
  • Agro-Meteorological Decision Engine: ICAR/IMD Gramin Krishi Mausam guidance (Irrigation schedule, pesticide spray window, soil moisture index).
  • Rural Multi-Channel Relay: 160-char DLT-compliant SMS string, Village IVR Loudspeaker announcement audio preview, and WhatsApp broadcast.
  • 6 Indic Languages: English, हिन्दी, मराठी, বাংলা, తెలుగు, ਪੰਜਾਬੀ.
