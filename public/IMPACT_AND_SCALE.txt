WeatherGPT — IMPACT, SCALE & COST MODEL (transparent)
=====================================================
For SIH Round-2. Numbers are **planning models**, not audited production metrics.
Label every figure as estimate when speaking to judges.

A) PROBLEM & WHO BENEFITS
-------------------------
Primary:
  - Small/marginal farmers — irrigation & spray timing, rain risk
  - District schools — heat / outdoor activity calls
  - Travellers & local gov ops rooms — early situational awareness
Secondary:
  - Urban users (AQI + rain)
  - Hackathon / research demos of open met stacks

B) CURRENT REACH (this build)
-----------------------------
  - Channel: Progressive Web App + browser notifications
  - Identity: per-browser (localStorage), no national user DB yet
  - Languages live: Hindi, English
  - Measured users: **not claimed** until analytics deployed
    (honest: pilot stage / college + demo traffic only)

C) RURAL RELAY (no smartphone end-user)
---------------------------------------
Layered model (do not skip layers when pitching):

  L1 Smartphone user (app)
     → sees alert + can Share

  L2 Feature phone / no data
     → L1 user or village volunteer opens alert
     → taps "SMS text" / copies script
     → sends personal SMS or reads IVR script at loudspeaker / mandi board

  L3 Institutional bulk (production)
     → State agri / DDMA provides numbers (consent + DLT)
     → MSG91 / Twilio / gov SMS gateway
     → template: RED/AMBER only to reduce cost & fatigue

App support today: L1 + L2 tools (SMS body, WhatsApp, IVR script).
L3 = integration + MoU + DLT registration (roadmap).

D) COST MODEL (INR, approximate, 2026 planning)
-----------------------------------------------
Assumptions (state clearly if challenged):
  - Avg SMS India commercial: ₹0.12 – ₹0.25 / SMS (volume dependent)
  - Use ₹0.15 mid for math
  - Only RED (and optional AMBER) auto-SMS
  - Free tier web hosting (Vercel) + free met APIs for moderate QPS

Example district pilot:
  - 50,000 opted-in farmers
  - 4 RED events / year district-wide
  - 1 SMS per event per user
  → 50,000 × 4 × ₹0.15 = ₹30,000 / year SMS
  → Per user per year ≈ ₹0.60 SMS only

National sketch (illustrative, NOT a claim of deployment):
  - 10 million opted-in
  - 3 SMS/user/year average
  → 30e6 × ₹0.15 = ₹45 lakh / year SMS
  Add: gateway, DLT, support staff, redundancy — budget 2–4× for ops.

App/API infra at pilot:
  - Vercel hobby/pro + Neon free/pro: often < ₹2–5k/month early
  - LLM phrasing (optional): Gemini free tier or few thousand INR if paid
  - Dominant variable cost at scale = **SMS/voice**, not weather API

E) LATENCY TARGETS
------------------
  - Forecast API: typically 200–1500 ms (network)
  - Deterministic chat: < 100 ms after weather pack in memory
  - Optional LLM chat: +0.5–3 s
  - Alert poll: ~3 minutes client cadence (configurable); cron can be 1–5 min

F) GOVERNMENT / INSTITUTION TIE-UP PLAN (stages)
------------------------------------------------
Stage 0 (now): Open data + public demo + honesty docs
Stage 1: College/district agri university or DDMA pilot MoU
         - 1–2 blocks, consent forms, WhatsApp group + app
Stage 2: State agri portal deep-link / embed + DLT SMS templates
Stage 3: IMD authorised warning feed when licence available
         - Replace model colours with official polygons where present

Never claim Stage 2–3 complete without paperwork.
