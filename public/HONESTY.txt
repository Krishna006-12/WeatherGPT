WeatherGPT — HONESTY SHEET (Round-2 / Technical Judges)
======================================================
Last updated: 2026-08-25
Purpose: Stop overclaim. Transparent engineering for Smart India Hackathon.

1) IS THERE A REAL LLM?
-----------------------
DEFAULT:
  - Grounded RAG Intent Router + Tool-Calling Architecture.
  - Strictly grounded on live meteorological JSON pack (temperature, precipitation, alerts, agromet indices).
  - Strength: Controllable, instant (<50ms), source-attributed, 100% demo-stable.
  - Zero hallucination guarantee: refuses to guess unverified weather data.

OPTIONAL LLM CALL:
  - Supports Gemini 1.5 Flash / Groq Llama-3 if server API key is configured.
  - LLM is strictly constrained via system prompt to phrase ONLY verified meteorological JSON tool payloads.

2) METEOROLOGICAL DATA SOURCES
------------------------------
LIVE SOURCES USED:
  - Open-Meteo High-Resolution Numerical Weather Prediction (NWP).
  - NOAA GFS (Global Forecast System) + ECMWF IFS (European Center) + DWD ICON Multi-Model Ensemble.
  - CBM / Open-Meteo Air Quality Monitoring (PM2.5, PM10, AQI).
  - Open-Meteo Soil Moisture Index (0-7cm, 7-28cm root zone) + FAO Evapotranspiration (ET₀).

NATIONAL ROLLOUT ROADMAP (Stage 3):
  - Official IMD / MoES Open Data Portal API integration via Government MoU.

3) LANGUAGES (INDIC MULTILINGUAL)
---------------------------------
IMPLEMENTED IN LIVE APP:
  - English, Hindi (हिन्दी), Marathi (मराठी), Bengali (বাংলা), Telugu (తెలుగు), Punjabi (ਪੰਜਾਬੀ).
  - Web Speech API Voice Recognition (STT) + Speech Synthesis (TTS).
  - Scale Roadmap: Bhashini API (National Language Translation Mission).

4) RURAL RELAY (NO-SMARTPHONE REACH)
-----------------------------------
IMPLEMENTED TODAY:
  - 160-Character DLT-compliant SMS string generator with native `sms:` intent.
  - WhatsApp Community & FPO Group Dispatch.
  - Village IVR Loudspeaker / Panchayat Audio Script with instant TTS voice preview.
  - Panchayat Emergency Broadcast Notice.

5) COST MODEL & VIABILITY
-------------------------
  - Cloud Infrastructure: Stateless serverless edge (₹0 on free tier).
  - Telecom DLT SMS: ~₹0.15 per SMS per event.
  - Pilot Model: 50,000 farmers in a district with 4 Red Alerts/year = ₹30,000/year (Funded via District Disaster Management Authority budget).
